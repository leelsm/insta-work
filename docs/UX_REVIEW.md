# 사용성 검토 및 개편

## 확인한 문제와 반영 내용

| 문제 | 변경 |
| --- | --- |
| 첫 화면에 모델·필수 설정 설명이 먼저 나와 시작 방법이 분산됨 | 사진, 글·뉴스, API 없는 예제 체험을 첫 화면의 세 가지 시작 경로로 제공 |
| 키 미등록 상태에서 무엇부터 해야 하는지 모호함 | 서비스별 연결 카드와 입력 → 모델 선택 → 테스트 흐름 제공 |
| 제작 중 모델 변경을 위해 설정 페이지로 이동해야 함 | 뉴스·사진·편집 화면에 서비스와 모델 선택 추가, 연결 관리 창에서 작업 유지 |
| Claude·Ollama 선택 후에도 생성 API가 OpenAI 키를 요구함 | 실제 선택한 제공자의 필수 설정만 검사 |
| 생성 도중 전역 모델 설정을 다시 읽어 작업 모델을 보장하기 어려움 | 요청 시 설정 스냅샷을 고정하고 작업 이력·성공한 콘텐츠에 모델 기록 |
| OpenCode·FreeLLMAPI가 일반 호환 API에 섞여 연결하기 어려움 | 전용 연결 카드, 직접 호출과 OpenCode 경유 호출, 모델 목록 조회 추가 |
| 카드 편집 후 다음 단계가 불분명함 | ‘다음 · 영상 만들기’ 버튼과 단계별 안내 추가 |
| 디자인·계정 설정이 기본 제작 흐름을 복잡하게 만듦 | 디자인 추가 설정을 접고, 파일 내보내기 모드에서 게시 기능 숨김 |
| 다운로드가 WebView에서 차단되거나 영상 탐색으로 연결될 수 있음 | 데스크톱 다운로드 활성화, 미리보기와 첨부파일 다운로드 응답 분리 |
| 메뉴 접기 설정이 화면에만 적용됨 | 저장 API와 초기 복원을 연결 |

## 검증

- React / TypeScript 프로덕션 빌드.
- 기존 테스트 및 제공자 선택·키 분리·보안 모드·다운로드·OpenCode 응답 검증 테스트.
- 설치된 OpenCode 1.18.35로 로컬 모의 게이트웨이 호출: 선택한 모델·인증 전달과 JSON 응답 확인. 실제 사용자 키를 사용하지 않음.
- 브라우저에서 첫 화면, 연결 카드, OpenCode 연결 창 확인.
- API 키 없는 예제의 실제 30초 영상 제작, 검토 승인, 확대 재생, X로 닫은 뒤 승인 상태 유지 확인.

## 실서비스 연결에 필요한 항목

FreeLLMAPI 게이트웨이 서버 실행과 통합 키 등록이 필요합니다. 현재 기본 주소의 서버 응답과 키 등록을 확인하지 못했으므로 실제 제공자 생성 성공으로 표시하지 않습니다. OpenCode는 기존 로그인 또는 앱에 등록한 FreeLLMAPI 설정을 사용합니다. 사진 자막은 선택한 모델의 이미지 입력 지원과 실제 테스트가 필요합니다.

## 2026-10-10 시각 구조 재개편

- 홈을 사진 제작 중심의 큰 시작 영역, 글·뉴스 제작 및 예제 체험 영역, 실제 콘텐츠 썸네일 갤러리로 재구성.
- 접힌 카테고리 메뉴를 주요 화면에 바로 접근하는 메뉴로 변경하고 추가 설정만 접어 보관.
- 공통 제작 단계 표시와 접어서 볼 수 있는 AI 선택 영역 도입. 사진 추가가 주 작업으로 보이도록 설정 밀도를 낮춤.
- 밝은/어두운 테마의 기본 표면, 대비, 버튼, 간격을 새 스튜디오 스타일로 정리.
- 검증: TypeScript/Vite 빌드 통과, Chrome에서 홈과 사진 제작 화면 및 테마 전환 확인, macOS 앱에서 실제 저장 콘텐츠 및 AI 연결 상태 유지 확인. CSS 최근 작업 카드 이름 충돌을 별도 클래스 이름으로 수정.

## 영상 완성 후 흰 화면 수정

- macOS 실행 앱에서 완성 영상을 열 때 `window.pywebview?.api.set_video_review is not a function` 오류를 재현.
- 영상 검토 상태 전달을 네이티브 JavaScript 브리지에서 인증된 로컬 API로 변경. 진입·종료 요청을 순서대로 전달하고 전송 오류가 UI 렌더링을 중단하지 않도록 처리. macOS X 버튼 보호는 로컬 API 콜백으로 유지.
- 창 닫기 이벤트 전달은 CSP에서 차단되는 eval을 사용하는 evaluate_js 대신 직접 실행하는 run_js로 변경. 보안 정책은 유지.
- 카드 영상의 제작 요청이 접수되면 결과 탭으로 이동. 화면 예외 시 홈으로 복구할 수 있는 오류 화면 추가.
- 회귀 검증: Python 테스트 98개, 검토 상태 전달 순서/전송 오류 회복 테스트 2개 통과. TypeScript 및 Vite 빌드 통과.
- 최종 macOS 빌드 실사용 검수: 저장된 연습용 카드 영상이 흰 화면 없이 열리고, 창 X를 누르면 앱을 유지한 채 `내 콘텐츠`로 복귀함. 사진 영상 재생·확대·모달 X 복귀도 앞선 빌드에서 확인.
