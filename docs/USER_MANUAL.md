# 콘텐츠 스튜디오 사용 가이드

뉴스 자료나 사진으로 세로 영상을 만들고, 완성한 MP4를 인스타그램에 직접 올리는 순서입니다. 처음이라면 아래 순서대로 진행하세요.

## 1. 앱 실행과 화면 익히기

Mac에서 콘텐츠 스튜디오 앱을 실행합니다. 실행 중에는 로컬 서비스가 함께 동작하며, 창을 닫거나 ‘스튜디오 종료’를 누르면 서비스와 진행 중인 제작 작업이 종료됩니다. 저장한 콘텐츠와 완성된 영상은 남습니다.

왼쪽 메뉴에서 작업을 선택합니다.

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 시작하기 | 사진·글·예제 중 시작 방법 선택, 최근 콘텐츠 확인 |
| 내 콘텐츠 | 저장된 뉴스·일상 콘텐츠 검색과 이어서 편집 |
| 작업 이력 | AI 생성·영상 제작의 진행 상태와 오류 확인 |
| 뉴스 카드뉴스 | 뉴스 검색 또는 직접 자료 입력으로 제작 시작 |
| 일상 영상 | 사진을 올려 자막과 음악이 있는 영상 제작 |
| AI 연결 | ChatGPT · OpenAI API, Claude, OpenCode, FreeLLMAPI 등 연결 |
| 뉴스 검색 · AI 음성 | 네이버 검색 키와 OpenAI 음성 설정 |
| 인스타그램 계정 | 계정 연동 정보 관리; 직접 파일 게시에는 불필요 |
| 보안 · 로컬 저장 | 클라우드 AI 허용 또는 로컬 전용 선택 |
| 백업 · 진단 | 콘텐츠 백업·복원과 진단 파일 저장 |
| 사용 가이드 | 이 문서와 API 준비 안내 읽기 |

상단 ‘워크스페이스’ 왼쪽 버튼으로 메뉴 전체를 접거나 펼칩니다. 카테고리 화살표로 하위 메뉴도 접을 수 있습니다. 접힌 카테고리 아이콘을 누르면 펼쳐집니다. 메뉴 접힘 상태는 저장되어 다음 실행에도 유지됩니다. 상단 테마 버튼에는 현재 라이트·다크 모드가 표시되고, 누르면 반대 모드로 전환됩니다. 테마 선택은 저장됩니다.

## 2. 사용할 기능에 맞게 준비하기

모든 기능에 API 키가 필요한 것은 아닙니다. 자료와 자막을 직접 작성하면 AI 키 없이도 영상을 만들 수 있습니다.

| 원하는 기능 | 필요한 준비 |
| --- | --- |
| 뉴스 검색 | 네이버 Client ID와 Client Secret |
| AI 뉴스 초안·게시 문안 | 선택한 제공자, 모델, 해당 API 키; 로컬 Ollama는 실행 중인 서버·모델 |
| AI 사진 자막 | 위 AI 설정과 이미지 입력을 지원하는 비전 모델 |
| 음성 내레이션 | OpenAI 키, 음성 모델, 음성 선택 |
| 사진 영상 | JPEG·PNG·WebP 사진 1~10장 |
| 영상 저장·직접 게시 | 앱에서 영상 완성 후 Instagram 앱/웹 사용 |

[API 발급 · 계정 준비 안내](API_SETUP_GUIDE.md)를 열어 사용할 키를 준비하세요.

## 3. AI 연결하고 영상마다 선택하기

1. **연결 → AI 연결**에서 원하는 서비스의 ‘연결하기’를 누릅니다.
2. API 키와 필요한 서버 주소를 입력하고 모델을 선택합니다. ‘저장 후 모델 목록 불러오기’로 서비스가 제공하는 모델 ID를 확인할 수 있습니다.
3. ‘저장하고 연결 테스트’로 응답을 확인합니다. 테스트에는 사용료가 발생할 수 있습니다. ‘기본 AI로 사용’을 누르면 제작 화면의 기본값이 됩니다.
4. 뉴스·사진 제작 화면 위의 **이번 영상은 누구와 만들까요?**에서 AI 서비스와 모델을 선택합니다. 설정의 기본값을 바꾸지 않고 이번 작업의 모델만 지정할 수 있습니다.
5. **직접 만들기 · AI 없이**를 고르면 직접 자막을 작성합니다. 처음에는 시작하기 화면의 **예제로 먼저 체험하기**를 추천합니다.
6. 제작 중 ‘AI 연결 관리’를 열어 설정을 보완해도 작성하던 콘텐츠는 그대로 남습니다. 완료 버튼으로 제작 화면에 돌아오세요.
7. AI 생성 작업 이력에는 실제 선택한 서비스와 모델이 표시됩니다. 생성에 성공한 콘텐츠를 다시 열면 마지막으로 사용한 모델을 불러옵니다.

키 등록이나 모델 목록 조회, 텍스트 테스트 성공만으로 사진 입력 지원이 확인되지는 않습니다. 사진 자막에는 이미지 입력을 지원하는 모델을 선택하세요. AI는 대본·자막·문안을 생성하고, 앱은 이 컴퓨터에서 사진·카드를 합성해 영상을 만듭니다. 음성은 별도의 OpenAI 음성 설정을 사용합니다.

### FreeLLMAPI와 OpenCode 함께 사용하기

1. FreeLLMAPI 서버에서 제공자 키를 연결하고 통합 API 키를 발급합니다.
2. 앱의 **FreeLLMAPI** 카드에서 서버 주소(기본 `http://127.0.0.1:3001/v1`)와 통합 키를 저장합니다.
3. 이 컴퓨터에 OpenCode CLI를 설치합니다. 기존 OpenCode 연결을 사용한다면 `opencode auth login`으로 먼저 준비합니다.
4. **OpenCode** 카드의 모델을 `freellmapi/auto`로 저장하고 연결 테스트를 합니다. `freellmapi/auto:fast` 또는 `freellmapi/정확한모델ID`도 사용할 수 있습니다.
5. 제작 화면에서 **OpenCode**를 선택하고 AI 초안·자막을 생성한 뒤, 내용을 검토하고 ‘영상 만들기’를 누릅니다.

FreeLLMAPI를 직접 선택해도 됩니다. OpenCode의 다른 기존 연결은 `provider/model` 형식으로 지정하세요. OpenCode가 찾는 기본 경로는 PATH, `~/.opencode/bin`, `~/.local/bin`, Homebrew 설치 경로입니다. 생성 요청은 임시 작업 폴더에서 실행하며 도구 사용과 자동 공유를 끕니다. OpenCode 자체의 로컬 세션 기록에는 생성 자료가 남을 수 있습니다. OpenCode·FreeLLMAPI는 외부 AI를 사용할 수 있으므로 로컬 전용 모드에서는 차단됩니다.

## 4. 뉴스 카드뉴스 만들기

### 인기뉴스로 시작

1. **콘텐츠 만들기 → 뉴스 카드뉴스 → 네이버 인기뉴스**를 엽니다.
2. 한국 시간 기준 날짜를 선택하고 ‘인기뉴스 불러오기’를 누릅니다. 오늘부터 최근 90일 범위에서 조회할 수 있습니다.
3. 언론사별 많이 본 뉴스 1~5위를 확인합니다. 전체 언론사를 합친 순위가 아닙니다. 네이버 API 키는 필요 없으며, 인터넷 연결과 클라우드 허용 정책이 필요합니다.
4. 목록에서 키워드, 언론사, 언론사 내 순위로 찾습니다. 같은 날짜의 조회 결과는 최대 10분 동안 재사용합니다.
5. 원문을 확인한 뒤 ‘자료 추가’를 누릅니다. 랭킹은 제목만 제공하므로 카드뉴스에 사용할 요약·허가된 본문과 사용 권한 메모를 입력합니다.
6. ‘카드 편집 시작’을 누르고 카드를 직접 편집하거나 AI 초안을 생성합니다. 랭킹 제목만으로 기사 본문을 자동 생성하지 않습니다.

네이버 공개 페이지가 바뀌거나 접근을 제한하면 조회에 실패할 수 있습니다. 잠시 후 다시 조회하거나 일반 뉴스 검색·직접 자료 입력을 사용하세요. 날짜를 바꾼 뒤에는 불러오기 버튼을 다시 눌러야 합니다.

### 뉴스 검색으로 시작

1. **연결 → 뉴스 검색 · AI 음성**에서 네이버 발급 서비스를 선택하고 Client ID와 Client Secret을 저장합니다.
2. 연결 테스트를 합니다.
3. **콘텐츠 만들기 → 뉴스 카드뉴스**에서 ‘네이버 뉴스 검색’을 선택합니다.
4. 검색어·기간·정렬·제외어를 입력하고 검색합니다. 정렬은 최신순 또는 정확도순이며 실제 인기뉴스 순위가 아닙니다.
5. 제목·짧은 검색 요약과 원문 링크를 확인한 뒤 ‘요약으로 AI 초안’을 누릅니다. 네이버 검색 API는 기사 전문을 제공하지 않으므로 AI도 화면의 요약·직접 추가한 자료만 근거로 씁니다.

### 직접 자료로 시작

1. 뉴스 카드뉴스에서 ‘직접 자료 입력’을 선택합니다.
2. 제목과 본문을 작성하거나 TXT·Markdown 파일을 가져옵니다.
3. 필요한 출처 URL과 사용 권한 메모를 입력합니다.
4. ‘카드 편집 시작’을 누릅니다. 블라인드 등 다른 출처도 사용 권한이 있는 텍스트를 이 방식으로 입력합니다.

### 카드와 게시 문안 편집

1. 뉴스·인기뉴스 자료를 선택할 때 외부 AI 전송 안내가 표시됩니다. 동의하면 선택한 모델이 카드 제목·본문·자막 대본·게시 문안을 한 번에 제안하고, 완료 후 영상 만들기 화면을 엽니다. 사용을 취소하면 자료 편집 화면에서 직접 작성할 수 있습니다. AI 초안을 다시 요청할 때는 자료와 전송 안내를 확인합니다.
2. 생성 결과의 사실·숫자·출처를 검토합니다. 필요한 내용을 수정하고 카드 순서를 조절합니다.
3. 템플릿·브랜드·포인트 색상·목표 길이 등 화면의 제작 옵션을 선택합니다.
4. 게시글 본문과 해시태그를 확인합니다.
5. 변경사항을 저장합니다. 저장하지 않고 이동하면 확인 메시지가 나타납니다.

## 5. 사진으로 일상 영상 만들기

1. **콘텐츠 만들기 → 일상 영상**을 엽니다.
2. JPEG·PNG·WebP 사진을 1~10장 선택합니다. 큰 사진도 선택할 수 있으며, 업로드 전에 긴 변 1920px 이하로 자동 축소·압축합니다. HEIC 사진은 JPEG로 변환하세요.
3. 제목과 일상 설명을 입력하고 사진 순서를 정합니다.
4. 사진에 맞는 자막을 직접 작성하거나 ‘AI 자막 제안’을 실행합니다. AI 제안 시 축소 사진과 설명을 선택한 업체에 보냅니다. 로컬 Ollama를 사용하면 로컬 서버로 보냅니다.
5. 제안한 자막과 게시 문안을 읽고 원하는 말투로 수정합니다.
6. 장면 길이, 사진 채우기/전체 보기, 위치, 확대 효과, 전환, 자막 위치·스타일을 조절합니다.
7. 앱 제공 CC0 연주곡을 들어보고 선택하거나, 아래 **내 음악 파일 첨부**에서 MP3·M4A·WAV 파일을 추가합니다. 음악 없음도 선택할 수 있으며 음량과 시작 위치를 조절합니다.
8. 설정을 저장하고 영상을 만듭니다.

앱 제공 음악의 라이선스 안내를 함께 저장할 수 있습니다. 음악 라이선스와 별개로 사진·자료의 사용 권한도 확인하세요.

### 내 음악 파일 넣기

- **일상 영상:** 사진으로 프로젝트를 만든 뒤 편집 화면의 **사진 · 자막 · 음악** 탭을 엽니다. **이 순간의 배경음악 → 내 음악 파일 첨부 → 음악 파일 선택**을 누릅니다.
- **뉴스 카드 영상:** 프로젝트 편집 화면의 **영상 만들기** 탭에서 **영상 설정 → 배경음악 → 내 음악 파일 첨부**를 찾습니다.
- MP3, M4A, WAV 파일을 25MB 이하로 준비합니다. 첨부하면 앱 제공 곡 대신 해당 파일이 선택됩니다. 파일 이름과 미리듣기 플레이어를 확인하고 음량·시작 위치를 조절한 뒤 **영상 만들기**를 누릅니다.
- 곡을 바꾸려면 **다른 음악으로 바꾸기**를 누릅니다. 앱 제공 곡으로 돌아가려면 제공 곡을 선택하고, 소리 없이 만들려면 **음악 없이**를 선택합니다. 음악을 바꾸면 영상을 다시 만들어야 합니다.
- 직접 제작했거나 영상 게시에 사용할 권한이 있는 음악을 첨부하세요. 직접 첨부한 파일에는 앱 제공 곡의 CC0 라이선스가 적용되지 않습니다. 첨부 파일은 이 컴퓨터의 앱 데이터와 앱 백업에 보관됩니다.

### 실시간 미리보기와 영상 효과

- Mac과 iPhone의 편집 화면에서 **재생 / 일시정지**를 누르면 현재 장면 순서대로 미리보기가 재생됩니다. 시간 슬라이더로 원하는 구간을 바로 확인할 수 있습니다.
- **폰트 크기**는 24~96px, **사진 움직임**은 정지·서서히 확대·서서히 축소·왼쪽/오른쪽 이동, **장면 전환**은 바로 전환·어둡게 페이드로 선택할 수 있습니다. 이 설정은 모든 장면에 적용되며 수정 즉시 미리보기에 반영됩니다.
- Mac은 장면 목록의 드래그·화살표, iPhone은 사진 썸네일 드래그 또는 사진 도구의 앞/뒤 이동 버튼으로 순서를 바꿉니다. 사진과 자막이 함께 이동합니다.
- 자막 위치는 일시정지한 상태에서 드래그하세요. Mac 미리보기에는 선택한 배경음악도 재생됩니다. 뉴스 음성은 MP4 제작 시 합성되며 최종 장면 길이는 실제 음성 길이에 맞춰집니다.
- 변경 후 저장하고 MP4를 다시 만들면 선택한 크기·움직임·전환이 완성 영상에 반영됩니다. `.studio` 파일을 통한 Mac/iPhone 이동에도 설정이 유지됩니다.

### 자막 폰트와 위치 바꾸기

- 내려받은 **TTF 또는 OTF** 폰트 파일(20MB 이하)을 준비합니다. 영상 게시에 사용할 수 있는 폰트인지 확인하세요.
- **일상 영상:** 편집 화면의 **사진 · 자막 · 음악 → 장면 설정 → 자막 폰트와 위치 → 폰트 파일 선택**을 누릅니다.
- **뉴스 카드 영상:** **내용 · 자막 → 카드 편집 → 자막 폰트와 위치 → 폰트 파일 선택**을 누릅니다.
- 화면의 **미리보기 자막을 마우스로 드래그**해 옮깁니다. 키보드 방향키로도 조금씩 움직일 수 있습니다. 위치와 폰트는 이 프로젝트의 모든 장면에 적용됩니다.
- 변경 후 **저장 → 영상 만들기**를 누르면 실제 MP4에 반영됩니다. 첨부한 폰트는 백업에도 포함됩니다.

## 6. 음성 사용하기

뉴스 영상에 음성을 넣으려면 **뉴스 · 음성 API**에서 음성 모델과 음성을 설정하고 샘플을 들어보세요. OpenAI 키를 사용합니다. 콘텐츠 편집 화면에서 음성 사용 여부를 선택하고 내레이션 대본을 검토합니다. 음성을 사용하지 않으면 자막만 있는 영상을 만들 수 있습니다.

## 7. 영상 만들고 확인하기

1. 편집 내용을 저장합니다.
2. 카드 편집의 ‘다음 · 영상 만들기’를 누르고 ‘영상 만들기’를 실행합니다. 작업 이력에서 진행률과 메시지를 확인할 수 있습니다.
3. 제작이 끝나면 미리보기에서 처음부터 끝까지 재생합니다.
4. 글자 잘림, 사진 위치, 자막 타이밍, 음량과 마지막 장면을 확인합니다.
5. 수정할 부분이 있으면 편집·저장 후 다시 제작합니다.

‘영상 크게 보기’로 연 영상은 오른쪽 X 또는 Esc로 닫습니다. 영상 확인 중 프로그램 창의 닫기 버튼을 누르면 확대 영상을 먼저 닫고, 일반 영상 확인 화면에서는 내 콘텐츠 목록으로 돌아갑니다. 승인 상태는 유지됩니다. 프로그램을 종료하려면 왼쪽 메뉴의 ‘스튜디오 종료’를 누르세요.

제작 중 앱을 닫으면 작업이 중단됩니다. 다음 실행에서 작업 이력을 확인하고 다시 제작하세요.

## 8. 영상 저장하고 인스타그램에 게시하기

1. 완성 영상의 MP4 다운로드 버튼으로 파일을 저장합니다. 기본 영상은 1080×1920 세로 MP4입니다.
2. 필요하면 SRT 자막과 장면 이미지 ZIP도 내려받습니다.
3. 게시 문안을 복사합니다.
4. 휴대전화에서 게시하려면 MP4를 AirDrop 등으로 옮깁니다.
5. Instagram 앱 또는 웹에서 릴스 업로드를 열고 MP4를 선택합니다.
6. 문안·해시태그·커버와 대상 계정을 확인한 뒤 직접 게시합니다.

현재 앱은 영상을 외부로 업로드하지 않습니다. 파일로 직접 게시할 때는 이 앱에 인스타그램 API 계정을 연결할 필요가 없습니다. Instagram에서 게시한 결과가 앱의 상태에 자동 반영되지는 않습니다.

## 9. 콘텐츠 이어서 작업하기

대시보드의 최근 작업 테이블에서 제목이나 ‘이어서 편집’을 누릅니다. **내 콘텐츠**에서는 뉴스·일상 영상 필터와 제목 검색을 사용할 수 있습니다. **작업 이력**에서는 생성·제작 실패 이유와 진행 상태를 확인하고 해당 콘텐츠를 엽니다.

## 10. 자료 저장과 보안 선택

프로젝트·사진·완성 영상은 이 컴퓨터의 사용자 데이터 폴더에 저장됩니다. API 키는 Mac Keychain 또는 Windows 자격 증명 관리자에 보관되며 백업·진단 파일에 포함되지 않습니다.

**보안 · 로컬 저장**의 ‘클라우드 AI 허용’에서는 선택한 AI 업체에 자료·축소 사진을, 네이버에 검색어를, OpenAI에 음성 대본을 전송합니다. 업체별 보관 정책이 적용됩니다. 외부 전송 없이 사용하려면 ‘로컬 전용’으로 바꾸고 Ollama 또는 직접 편집을 사용하세요. 로컬 전용에서는 외부 뉴스·음성·계정 API도 차단됩니다.

## 11. 백업하고 다른 컴퓨터로 옮기기

### iPhone과 프로젝트 옮기기

iPhone 앱은 iOS 17 이상에서 Mac 서버 없이 일상 사진 영상 편집과 MP4 제작을 수행합니다. Mac은 카드뉴스와 일상 영상을 모두 제공하고 iPhone은 일상 영상에 집중합니다. 홈에서 **새 일상 영상 → 사진 선택 → 분위기·자막**으로 시작하고, 편집 화면의 **사진 / 자막 / 효과 / 음악** 도구로 설정합니다. 미리보기 재생·시간 이동·전체 화면 확대가 가능하고 편집 내용은 자동 저장합니다.

Mac 일상 편집 화면의 **iPhone용 프로젝트**로 `.studio` 파일을 만듭니다. AirDrop 또는 파일 앱으로 옮기고 iPhone 홈의 **앱 설정 → 일상 영상 가져오기**로 엽니다. 사진·음악·폰트·장면·자막·움직임·전환·분위기·설명·말투·음악 시작 구간이 포함됩니다. MP4는 별도로 저장하거나 공유하세요.

iPhone의 **영상 메뉴 → 게시 문안 · Mac으로 보내기 → 프로젝트 파일 만들기**에서 내보내고, Mac의 **내 콘텐츠 → iPhone 프로젝트 가져오기**로 엽니다. 기존 콘텐츠를 덮지 않고 새 프로젝트로 가져옵니다. 기존 iPhone 카드 프로젝트는 홈의 **앱 설정 → 이전 카드 프로젝트를 Mac으로 보내기**에서 내보냅니다. API 키와 계정 토큰은 프로젝트 파일에 포함되지 않습니다.

일반 다운로드용 TestFlight 링크는 아직 없습니다. 설치 방법은 [iPhone 설치 안내](../ios/README.md)를 따르세요.

## 12. 문제가 생겼을 때

| 증상 | 확인할 것 |
| --- | --- |
| 앱 실행 실패 | OS·CPU에 맞는 앱인지 확인하고 시작 오류 안내 확인 |
| 뉴스 검색 실패 | 발급 서비스·네이버 키 두 개·검색어 확인 후 연결 테스트 |
| AI 생성 실패 | 화면의 오류 코드를 확인합니다. `credit_balance_exhausted`는 OpenAI API 선불 잔액 소진, `rate_limit_exceeded`는 일시적인 요청 제한입니다. 잔액·한도 문제를 해결한 뒤 다시 제안하세요. |
| 사진 AI 자막 실패 | 이미지 입력을 지원하는 모델인지 확인 |
| Ollama 연결 실패 | 서버 실행 상태·로컬 주소·모델 설치 여부 확인 |
| 글자 잘림 | 제목·본문을 줄이거나 카드를 나눠 다시 제작 |
| 음성 실패 | OpenAI 키·음성 모델·음성 선택과 클라우드 허용 여부 확인 |
| 제작 중단 | 작업 이력 메시지 확인 후 저장된 콘텐츠에서 다시 제작 |
| 다른 Mac에 키가 없음 | 키는 앱 파일·백업에 포함되지 않으므로 새로 등록 |

필요하면 백업 · 진단에서 진단 파일을 저장하세요. 키·토큰을 채팅이나 오류 보고에 붙여 넣지 마세요.

## AI 초안에서 영상 저장까지 한 번에 진행하기

뉴스 검색 결과에서 **기사 요약 가져오기**를 누르면 앱이 원문 페이지를 확인해 핵심 문장을 추려 **기사 본문 요약** 필수란에 자동으로 넣습니다. 요약을 직접 확인·수정한 뒤 AI 초안을 시작하세요. 원문 사이트가 본문을 제공하지 않으면 검색 요약을 대신 넣고 이유를 표시합니다. 인기뉴스는 제목만 제공하므로 원문을 열어 직접 요약을 입력해야 합니다.

선택된 AI 모델에 제목·요약을 보내도 되는지 확인한 뒤, 동의하면 카드 5장, 장면별 본문·자막 대본과 게시 문안을 제안하고 **영상 만들기** 화면으로 이동합니다. 각 카드에는 내용에 맞는 Wikimedia Commons 검색어와 공개 라이선스 이미지가 제안됩니다. 카드 편집의 **카드 관련 이미지**에서 다른 이미지를 찾거나 내 컴퓨터의 이미지를 선택할 수 있습니다. 영상에는 작가와 라이선스가 표기되고, 게시 문안에는 카드별 이미지 출처·라이선스 링크가 붙습니다. 카드와 자막을 고치고 저장한 뒤 영상을 만드세요.

이미지 검색은 인터넷 연결이 필요합니다. 로컬 전용 모드에서는 외부 검색을 차단하며, 직접 가진 이미지를 선택할 수 있습니다. Wikimedia Commons 이미지는 CC BY, CC BY-SA, CC0 또는 퍼블릭 도메인으로 표시된 자료만 제안하지만, 게시 전에 카드와 작품 정보의 저자·라이선스를 확인하세요.

사진 영상은 사진을 추가한 뒤 **AI 자막 제안으로 영상 만들기** 또는 **직접 자막 쓰기**를 선택합니다. AI 제안에는 전송 동의가 필요하고, 완료되면 사진·자막·음악을 한 화면에서 확인할 수 있습니다. AI 오류가 나도 저장한 사진과 자료는 남습니다. 오류 메시지를 확인하고 다시 제안하거나 자막을 직접 입력하세요.
