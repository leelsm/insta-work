## v0.2 일상 영상 스튜디오

콘텐츠 만들기 아래에 뉴스 카드뉴스와 일상 영상 메뉴를 분리했습니다. 공통 프로젝트 보관함에서 유형별로 필터할 수 있습니다. 디자인은 짙은 차콜 배경과 보라색 포인트를 사용하는 스튜디오 형태입니다.

일상 영상에서 JPEG·PNG·WebP 사진 1~10장을 올리고 순서를 정하세요. 큰 사진도 업로드 전에 긴 변 1920px 이하로 자동 축소·압축하며 HEIC는 JPEG로 변환한 뒤 추가하세요. 사진은 로컬에 저장하고 EXIF 위치 정보를 제거합니다. AI 자막 제안을 실행할 때만 축소한 사진과 작성한 설명을 OpenAI에 전송하며 API 비용이 발생합니다. 제안된 자막과 게시 문안은 수정할 수 있습니다.

장면 길이, 채우기/전체 보기, 사진 위치, 확대 효과, 전환, 자막 위치·스타일을 설정하세요. 음악은 앱 제공 오리지널 CC0 연주곡 3개 중 추천곡을 듣고 선택하거나 음악 없이 만들 수 있습니다. 음악 볼륨과 시작 위치를 조절할 수 있습니다. 외부 음원 검색은 제공하지 않습니다. 플랫폼 자동 음원 판정 결과를 보장하지는 않습니다.

영상 만들기를 실행하면 1080×1920 MP4, SRT 자막, 장면 이미지 ZIP, 선택한 음악의 라이선스 안내를 내려받을 수 있습니다. 결과를 확인한 뒤 인스타그램에서 직접 올리거나, 연결된 계정으로 기존 수동 승인·게시 흐름을 사용하세요. 자동 예약 게시 기능은 Phase 2입니다. 사진 원본도 백업 ZIP에 포함되므로 백업을 안전하게 보관하세요.

v0.2 검증: 자동 테스트 26개 통과. 실제 FFmpeg로 사진 2장·4초·줌·페이드·CC0 배경음악·한국어 자막 MP4 생성 및 다운로드, 사진 백업 복원 검증. 프런트엔드 TypeScript/Vite 빌드 성공. Windows/Intel macOS 실행은 해당 OS에서 추가 검증이 필요합니다.


## v0.3 모델 선택 · 테마 · 보안 정책

계정 · API 설정 하위 메뉴: AI 모델 설정, 뉴스 · 음성 API, 인스타그램 계정, 보안 · 로컬 저장, 백업 · 진단. AI 모델 설정에서 OpenAI, Claude, OpenAI 호환 API, 로컬 Ollama를 선택하고 모델 이름을 입력합니다. 제공자별 키는 OS 보안 저장소에 따로 저장하며 서로 공유하지 않습니다. 저장 후 생성 테스트는 소량 API 사용료가 발생할 수 있습니다. 콘텐츠 화면 상단에서 현재 모델을 확인하고 변경할 수 있습니다. 생성은 뉴스 초안/사진 자막을 만들며, 영상 합성은 로컬 FFmpeg가 수행합니다. 사진 기능은 이미지 입력을 지원하는 비전 모델이 필요합니다. 외부 API가 실패하면 다른 업체로 자동 전송하지 않고 기존 초안을 보존합니다.

Claude: https://platform.claude.com 에서 API 키·사용 가능 모델을 확인하세요. Messages API를 사용합니다. OpenAI 호환 서비스는 HTTPS 기본 주소(/v1 포함)와 해당 업체에서 발급받은 키·모델을 입력합니다. Chat Completions 및 JSON 객체 응답을 지원해야 합니다. OpenCode 같은 개발 도구 이름만으로 특정 API를 연결할 수는 없으므로 실제 제공자와 API 주소를 확인하세요. FreeLLM도 제공하는 API 형식·비전 모델 지원·약관을 확인해야 합니다.

로컬 Ollama: https://ollama.com 에서 OS에 맞게 설치하고 사용할 모델을 다운로드·실행합니다. 기본 API 주소는 http://127.0.0.1:11434/v1 입니다. 텍스트 모델은 뉴스 초안만, 비전 모델은 사진 자막까지 처리할 수 있습니다. 설치·모델 다운로드에는 인터넷이 필요하지만 앱의 로컬 모델 생성 요청은 localhost로만 보냅니다. 시스템 프록시와 HTTP 리디렉션도 사용하지 않습니다. 모델·서버 설치 및 실제 생성 호환성은 사용하는 환경에서 확인해야 합니다.

상단 라이트/다크 버튼으로 테마를 바꾸며 선택은 이 컴퓨터에 저장됩니다. 앱 테마는 출력 영상 템플릿을 바꾸지 않습니다.

보안 · 로컬 저장에서 정책을 선택합니다. 클라우드 AI 허용은 자료·축소 사진을 선택한 AI 업체에, 음성 텍스트를 OpenAI에, 뉴스 검색어를 네이버에 전송합니다. 공개 게시가 아니어도 업체 보관 정책이 적용됩니다. OpenAI 생성 요청에는 store:false를 사용하지만 이는 모든 업체 로그·보관을 없앤다는 뜻이 아닙니다. 외부 전송을 전혀 원하지 않으면 로컬 전용으로 바꾸고 Ollama 또는 직접 편집을 사용하세요. 이 모드는 외부 뉴스·음성·계정 API도 차단합니다.

이전 S3/인스타그램 직접 게시 기능과 달리 현재 기본 정책은 영상 외부 업로드 차단입니다. MP4를 로컬에 내려받아 사용자가 인스타그램에서 직접 게시합니다. API 키는 Keychain/Credential Manager에 저장되며 프로젝트·백업·진단에 포함되지 않습니다. API 키는 요청 인증을 위해 해당 발급 업체로 전달됩니다. 로컬 웹 서버는 127.0.0.1만 사용하고 세션·변경 요청 토큰을 검사하며, 외부 사이트 접근을 차단합니다. 백업은 사진·영상이 포함된 일반 ZIP이며 암호화되지 않으므로 파일 자체도 안전하게 보관하세요.


v0.3 검증: 자동 테스트 39개 통과. 제공자별 요청 형식·인증키 분리, 로컬 전용 외부 요청 차단, 영상 업로드 기본 차단, 테마 정책 보존·저장 검증. 라이트/다크와 설정 하위 메뉴를 macOS 실행 앱에서 확인했습니다. Claude·호환 API·Ollama의 실제 생성은 해당 키·로컬 서버를 준비한 뒤 연결 테스트가 필요합니다.


모델 현황 개선 검증: 전체 자동 테스트 46개 통과. 저장 설정 기준 현황, 키 미등록/선택/정책 차단 구분, 테스트 결과 로컬 저장·모델/주소/키 변경 무효화, 설정 변경 중 이전 테스트 결과 제외, 조회 시 키 접근·외부 요청 없음 검증.


## 현재 테마와 기능별 필수값

상단 테마 버튼은 현재 적용된 ‘라이트 모드’ 또는 ‘다크 모드’를 표시합니다. 클릭하면 반대 테마로 바뀝니다. 대시보드의 콘텐츠별 준비 카드에서 뉴스 초안과 사진 자막에 적용되는 모델을 확인하세요. 현재 두 기능은 하나의 콘텐츠 생성 모델 설정을 공유합니다.

AI 모델 설정의 ‘필수’ 항목을 입력하세요. 클라우드 AI는 제공자·모델·API 키가 필요하며, 호환 API는 HTTPS 기본 주소도 필요합니다. Ollama는 모델과 로컬 API 주소, 실행 중인 로컬 서버가 필요합니다. 키는 불필요합니다. 사진 AI 자막은 이미지 입력을 지원하는 비전 모델을 사용해야 합니다. 미설정 항목이 있으면 생성 테스트 버튼을 비활성화하고 누락된 항목을 표시합니다. 설정 초안 저장은 가능합니다.

네이버 키 두 개는 뉴스 검색 사용 시 필수이며, 직접 자료 입력에는 필요하지 않습니다. 음성 사용 시 OpenAI 키·음성 모델·음성 선택이 필요합니다. 일상 영상 제작에는 사진 1~10장이 필요하지만 직접 자막을 쓰는 경우 AI 키는 필요하지 않습니다. 로컬 전용 정책으로 차단된 기능은 설정 누락과 별도로 안내합니다.

앱 내 가이드/메뉴 개선: 자동 테스트 53개 통과. 포함된 가이드 5개 조회, 인증·허용 목록, 메뉴 및 카테고리 상태 로컬 DB 저장, 일반 설정 저장 시 메뉴 상태 보존, 화면 설정 입력값·변경 요청 인증을 검증했습니다. macOS 실행 파일은 iOS에서 실행할 수 없습니다.


## 2026-10-11 iPhone 일상 영상 전용 UI

Mac은 카드뉴스·일상 영상 메뉴를 유지하고 iPhone 홈·제작·편집은 일상 영상 전용으로 개편했습니다. 두 단계 사진 선택·분위기 입력, 큰 실시간 미리보기와 전체 화면 확대, 사진 썸네일 순서 변경, 사진/자막/효과/음악 하단 도구, 고정 저장 버튼을 제공합니다. 기존 카드 데이터는 Mac 내보내기용으로 보존합니다.

iPhone에 사진 위치·교체·장면 길이 0.5초 단위, 음악 미리듣기·시작 구간·시작/끝 페이드, 실제 사진 입력 AI 자막 요청을 추가했습니다. `.studio` 교환에 분위기·설명·말투·음악 시작 구간을 보존합니다. 유료 AI 요청은 검증 과정에서 실행하지 않습니다.
