# 2차 QA 결과 · 2026-10-15

1차 수정 커밋 `32f7f80` 이후 크로스페이드, 컬러 이모지, 자막 속도 경고를 검증했습니다. QA 담당은 Mac·웹과 iPhone·프로젝트 교환 두 명으로 나누었습니다. 사용자 저장소 대신 임시 데이터·프로젝트를 사용했습니다.

## 구현 및 재현 결함 수정

- Mac·iPhone·웹 재생 미리보기에서 장면 경계 앞뒤 약 0.25초 동안 두 장면을 섞습니다. 첫·마지막 화면, 장면 길이 합과 SRT 시간은 유지합니다.
- Mac 자막·카드의 이모지는 AppKit의 Apple Color Emoji로 그립니다. 한글·영문은 선택한 폰트를 사용하고 이모지 폭을 줄바꿈에 반영합니다.
- 웹 카드뉴스·일상 영상과 iPhone 자막 도구에 읽기 시간 경고를 표시합니다. 공백을 뺀 글자 수 ÷ 7 + 1초를 0.5초 단위로 올리고, 버튼을 눌렀을 때만 장면당 2~30초·전체 180초 범위에서 적용합니다.
- QA에서 긴 웹 자막의 UTF-16 분할이 복합 이모지를 깨뜨리는 문제를 재현했습니다. 렌더러와 같은 코드 포인트 기준으로 나누되 이모지 조합을 보존하도록 수정하고, 6종 회귀 검사 및 브라우저 재검증을 통과했습니다.
- 장면당 30초 제한을 전체 180초 제한으로만 설명하던 경고 문구를 수정했습니다. 웹·iPhone에서 두 한도를 함께 안내합니다.

## 검증 범위

CoreSimulator의 실행 환경 탐색·앱 설치 지연이 발생했습니다. 서비스 재시작 후 시뮬레이터 실행 파일은 동작했으나, 전체 86개 검사 중 기존 음악의 AVAssetExportSession 오디오 합성이 오래 걸려 전체 완료 결과는 확보하지 못했습니다. iPhone 화면에서 경고 버튼을 직접 누르는 검사는 완료하지 못했습니다. iPhone 검증 결과는 앱 빌드, 실제 프로젝트 교환 코드, 변경 사항의 별도 렌더링 검사 범위로 구분합니다.

실기기 설치·서명, 유료 AI 호출, 실제 사용자 프로젝트 변경은 수행하지 않았습니다. Mac `.app`은 `dist/ContentStudio.app`에 생성했습니다. 정식 배포 서명·공증 결과물은 아닙니다.
