# 자막 폰트

2026-10-11에 눈누의 조회수와 자막 가독성을 참고해 선택했습니다. 현재 인기 순위 상위 5개라는 의미는 아닙니다.
영상 사용 및 앱 번들/재배포는 각 폰트의 SIL OFL 1.1에 따라 허용됩니다. 저작권 안내와 라이선스 전문을 함께 배포해야 하며 폰트 자체의 단독 판매는 금지됩니다.

폰트 원본의 SHA-256 앞 32자를 자산 ID로 사용합니다. `catalog.json`을 Mac과 iPhone 앱에서 공통으로 읽습니다.
Mac 선택 목록은 `/api/fonts/library`에서 앱에 포함된 폰트를 로컬 자산으로 복사하고, iPhone은 선택 시 번들에서 복사합니다.
인터넷 연결 없이 선택·미리보기·MP4 제작에 사용할 수 있습니다.
